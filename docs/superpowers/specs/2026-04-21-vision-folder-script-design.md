# Vision Folder Script — Design Spec

**Date:** 2026-04-21
**Status:** Approved

## Context

The project has a visual intelligence pipeline (frame extraction → CLIP classification → slide/notebook/whiteboard ingestion into Qdrant). There is no script to drive this pipeline over a folder of class directories. This script fills that gap, following the same pattern as `scripts/transcribe_folder.py`.

## Folder Convention

Each class directory has a fixed layout:

```
<class_dir>/
├── documentos/    ← .pptx files (slides)
├── scripts/       ← .ipynb files (notebooks)
├── video/         ← .mp4 and other video files
└── ai_data/       ← generated by pipeline
    └── {video_stem}_frames/
        ├── frame_0001.jpg
        └── classifications.json
```

A directory is a valid class dir if it contains a `video/` subfolder.

## Script

**File:** `scripts/vision_folder.py`

### CLI

```
python scripts/vision_folder.py <root_folder> [options]

Positional:
  root_folder       Root directory to scan for class directories

Options:
  --steps           Comma-separated steps to run (default: all)
                    Choices: extract, classify, slides, notebooks, whiteboards
  --interval INT    Frame extraction interval in seconds (default: 5)
  --recursive       Also scan subdirectories of root_folder for class dirs
  --dry-run         Print actions without executing them
```

### Steps

| Step | API Endpoint | Input | Idempotent skip condition |
|---|---|---|---|
| `extract` | `POST /extract-frames` | `file_path`, `interval` | frames dir exists and is non-empty |
| `classify` | `POST /classify-frames` | `frames_dir` | `classifications.json` exists |
| `slides` | `POST /ingest/slides` | `pptx_path`, `video_path`, `frames_dir`, `interval` | none (always runs) |
| `notebooks` | `POST /ingest/notebook` | `ipynb_path`, `video_path`, `frames_dir`, `interval` | none (always runs) |
| `whiteboards` | `POST /ingest/whiteboard` | `video_path`, `frames_dir`, `interval` | none (always runs) |

### Processing Logic

For each class directory found:
1. Find all videos in `video/` matching VIDEO_EXTENSIONS
2. Find all `.pptx` in `documentos/`
3. Find all `.ipynb` in `scripts/`
4. For each video:
   - Compute `frames_dir = <class_dir>/ai_data/{video_stem}_frames`
   - Run each requested step in order, skipping where applicable
   - `slides` runs once per (video, pptx) pair
   - `notebooks` runs once per (video, ipynb) pair
   - `whiteboards` runs once per video (no companion file needed)

### Error Handling

- API errors are caught per step; processing continues for remaining videos
- If `extract` fails, skip `classify`, `slides`, `notebooks`, `whiteboards` for that video
- If `classify` fails, skip `slides`, `notebooks`, `whiteboards` for that video
- Print error inline and increment failure counter
